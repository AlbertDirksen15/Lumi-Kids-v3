# Состояние сборки Lumi Kids

## Что есть в исходниках

В проекте есть Android-код, шесть сценариев уроков, словарь, манифест, конфигурация Gradle, скрипты Vosk/Piper и GitHub Actions.

## Чего нет в исходной папке

Готового Lumi Kids APK не найдено. Голосовые WAV-файлы и модели Vosk также не хранятся в репозитории исходников: README проекта указывает, что они подготавливаются отдельно в CI.

Поэтому после восстановления нужно сначала подготовить голосовые ресурсы, а затем собрать APK.

## Локальная сборка

Требуются:

- Android Studio;
- Android SDK 35;
- JDK 17;
- Gradle 8.9;
- доступ к загрузке моделей Vosk и инструментам Piper.

Откройте корень проекта в Android Studio и выполните инструкции из `scripts/`. Затем соберите debug-вариант:

```text
app/build/outputs/apk/debug/
```

## Сборка через GitHub Actions

В репозитории сохранён workflow:

```text
.github/workflows/build-apk.yml
```

После запуска workflow он проверяет словарь и сценарии, подготавливает модели и голосовой пакет, собирает APK и загружает его как artifact. Это основной способ получить установочный APK без ручной настройки окружения.
