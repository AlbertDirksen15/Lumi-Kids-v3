# Структура проекта Lumi Kids

## Что хранится в GitHub

- `app/` — Android-код, ресурсы, словарь и сценарии;
- `scripts/` — проверка материалов, Vosk и генерация голосов;
- `.github/workflows/` — автоматическая сборка APK;
- `docs/` — описание архитектуры, сборки, восстановления и версий;
- `VERSION` — текущая версия проекта;
- `CHANGELOG_RU.md` — история изменений.

## Что не хранится в GitHub

- `app/build/` и другие результаты локальной сборки;
- `.gradle/`, `.idea/`, `local.properties`;
- скачанные Vosk/Piper-модели, которые создаются workflow;
- личные данные, базы, Telegram-сессии и токены;
- чужие APK и файлы, не относящиеся к Lumi Kids.

Большой резервный ZIP проекта хранится отдельно на компьютере:
`D:\Загрузки\детский английски\Lumi-Kids-v3-Codex-Handoff.zip`.

## Как определить последнюю версию

1. Откройте `VERSION` в ветке `main`.
2. Сверьте изменения в `CHANGELOG_RU.md`.
3. Для установочного файла откройте последний успешный запуск workflow `Build Lumi Kids v3 APK` и скачайте артефакт `Lumi-Kids-v3-APK`.

APK не добавляется в исходники, чтобы репозиторий не разрастался и каждая сборка была связана с конкретным коммитом.
