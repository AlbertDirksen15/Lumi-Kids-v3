# Восстановление Lumi Kids после переустановки Windows

1. Клонируйте репозиторий:
   `git clone https://github.com/AlbertDirksen15/Lumi-Kids-v3.git`
2. Откройте папку проекта в Android Studio.
3. Установите JDK 17 и Android SDK 35.
4. Проверьте, что Gradle видит Android SDK.
5. Запустите `scripts/validate_content.py`.
6. Подготовьте Vosk и Piper по скриптам.
7. Запустите GitHub Actions или локальную debug-сборку.
8. Установите полученный APK на устройство.

## Резервные копии

На диске F: отдельно сохранён локальный проект/архив Lumi Kids. Репозиторий GitHub содержит исходники и документацию; локальный ZIP может быть крупнее лимита обычного GitHub-файла, поэтому его не следует считать заменой Git-истории.

## Что сохраняется в приложении

Прогресс пользователя хранится локально на Android-устройстве в SQLite. Он не находится в исходниках GitHub и должен резервироваться отдельно с устройства, если это потребуется.
