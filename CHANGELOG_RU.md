# История версий Lumi Kids

## 3.0.0 — текущая версия

- восстановлен исходный проект Lumi Kids v3;
- добавлены игровые сценарии Animals, Colors, Numbers, Family, Food и Body;
- добавлены словарь и локальный прогресс;
- добавлены офлайн-озвучка и опциональное распознавание речи;
- добавлена автоматическая сборка debug APK через GitHub Actions;
- добавлены инструкции восстановления и структура материалов;
- исключены пользовательские данные, Telegram-сессии, кэши и файлы сборки.

Готовый APK публикуется только как артефакт успешной сборки GitHub Actions и не хранится в исходниках.
