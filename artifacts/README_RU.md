# APK и релизные файлы

На момент публикации готового APK Lumi Kids в локальных материалах не найдено. Здесь оставлена папка для будущих APK.

После успешной сборки добавьте сюда, например:

```text
Lumi-Kids-v3-debug.apk
```

APK лучше публиковать как GitHub Release asset или artifact GitHub Actions, а не хранить в Git, если размер превышает лимит обычного файла GitHub.
