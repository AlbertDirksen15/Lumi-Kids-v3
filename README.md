# Lumi Kids v3

Офлайн-приложение-игра для изучения английского, немецкого и русского языков детьми.

## Статус

В репозитории находятся исходники проекта, игровые сценарии, словарь, Android-конфигурация, скрипты подготовки голосовых материалов и GitHub Actions для сборки APK.

Готового APK Lumi Kids в исходной папке не найдено. Поэтому этот репозиторий является восстанавливаемым исходным проектом, но не готовым установочным пакетом.

## Возможности

- персонаж Lumi с анимациями и реакциями;
- уроки Animals, Colors, Numbers, Family, Food и Body;
- игровые задания: выбор цвета, счёт, память, сортировка, drag-and-drop;
- режимы для дошкольников и читателей;
- словарь на 1000 слов;
- направления EN/DE/RU;
- локальный прогресс и интервальное повторение;
- пользовательские слова из TXT/CSV;
- офлайн-озвучка и опциональное распознавание речи;
- без рекламы, аналитики, Firebase, Google Play Services и разрешения INTERNET.

## Структура

- `app/src/main/java/` — исходный Java-код;
- `app/src/main/assets/` — словарь и сценарии уроков;
- `app/src/main/res/` — Android-ресурсы;
- `docs/` — архитектура, сценарии и инструкции восстановления;
- `scripts/` — проверка контента, Vosk и генерация голосового пакета;
- `.github/workflows/build-apk.yml` — автоматическая сборка APK.

## Сборка

Нужны Android SDK 35, JDK 17 и Gradle 8.9.

1. Откройте проект `LumiKidsV3` в Android Studio.
2. Запустите подготовку моделей и голосовых ресурсов по инструкциям в `docs/BUILD_STATUS_RU.md`.
3. Выполните сборку debug APK.
4. APK появится в `app/build/outputs/apk/debug/`.

Также можно запустить workflow **Build Lumi Kids v3 APK** в GitHub Actions.

## Восстановление

Полная инструкция находится в `docs/RESTORE_RU.md`. Исходная папка и ZIP-архив проекта остаются локально на диске D: как дополнительная резервная копия.

## Лицензии и материалы

Перед публикацией приложения проверьте права на голосовые модели, словарь и сторонние компоненты. Репозиторий содержит код и учебные материалы проекта, но не содержит личных Telegram-сессий или данных пользователя.
