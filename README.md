# Lumi Kids v3

Офлайн-приложение-игра для изучения английского, немецкого и русского языков детьми.

## Текущая версия

**3.0.0** — указана в файле [`VERSION`](VERSION). История изменений находится в [`CHANGELOG_RU.md`](CHANGELOG_RU.md).

## Статус

В репозитории находятся исходники проекта, игровые сценарии, словарь, Android-конфигурация, скрипты подготовки голосовых материалов и GitHub Actions для сборки APK.

Готовый APK не хранится среди исходников. Он создаётся автоматически после успешной сборки и доступен в разделе **Artifacts** соответствующего запуска workflow. Это позволяет точно связать APK с конкретной версией и коммитом.

## Возможности

- персонаж Lumi с анимациями и реакциями;
- уроки Animals, Colors, Numbers, Family, Food и Body;
- игровые задания: выбор цвета, счёт, память, сортировка, drag-and-drop;
- режимы для дошкольников и читателей;
- словарь на 1000 слов;
- направления EN/DE/RU;
- локальный прогресс и интервальное повторение;
- пользовательские слова из TXT/CSV;
- офлайн-озвучка и опциональное распознавание речи;
- без рекламы, аналитики, Firebase, Google Play Services и разрешения INTERNET.

## Структура

- `app/src/main/java/` — исходный Java-код;
- `app/src/main/assets/` — словарь и сценарии уроков;
- `app/src/main/res/` — Android-ресурсы;
- `docs/` — архитектура, сценарии, версии и инструкции восстановления;
- `scripts/` — проверка контента, Vosk и генерация голосового пакета;
- `.github/workflows/build-apk.yml` — автоматическая сборка APK.

Полная карта файлов и правила хранения описаны в [`docs/PROJECT_LAYOUT_RU.md`](docs/PROJECT_LAYOUT_RU.md).

## Сборка

Нужны Android SDK 35, JDK 17 и Gradle 8.9.

1. Откройте проект в Android Studio.
2. Запустите подготовку моделей и голосовых ресурсов по инструкции в [`docs/BUILD_STATUS_RU.md`](docs/BUILD_STATUS_RU.md).
3. Выполните сборку debug APK.
4. APK появится в `app/build/outputs/apk/debug/`.

Также можно запустить workflow **Build Lumi Kids v3 APK** в GitHub Actions. Артефакт называется `Lumi-Kids-v3-APK`.

## Восстановление

Полная инструкция находится в [`docs/RESTORE_RU.md`](docs/RESTORE_RU.md). Большой ZIP-архив проекта остаётся отдельной локальной резервной копией на диске D:.

## Лицензии и материалы

Перед публикацией приложения проверьте права на голосовые модели, словарь и сторонние компоненты. Репозиторий содержит только материалы Lumi Kids, код и учебные данные проекта; личные Telegram-сессии и данные пользователя не включаются.
